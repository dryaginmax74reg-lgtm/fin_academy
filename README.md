# FINLAB — личная академия инвестиционного советника

Telegram-бот с ежедневными уроками + мини-приложение внутри Telegram. Курс соединяет экономику, финансовую математику, рынки России и мира, экономическую историю и практику работы с состоятельными клиентами.

## Что уже работает в проекте
- Ежедневная отправка урока в Telegram через GitHub Actions (08:00 по Москве, UTC+3; ручной запуск доступен в Actions).
- 30 полноценных стартовых уроков в `course/lessons.json`; после них бот продолжает по 12-месячной карте курса и честно сообщает, когда тема дана как план, а не как написанная статья.
- Мини-приложение `miniapp/index.html`: каталог курса, поиск, урок дня, карточки уроков, интерактивные тесты, заметки и прогресс в localStorage браузера.
- Еженедельные, месячные и квартальные экзамены описаны в программе; можно проходить прямо в Mini App.
- Бесплатный базовый стек: Python standard library + GitHub Actions + GitHub Pages. Внешний AI API не нужен.

> Важно: это учебная система, не инвестиционная рекомендация. Текущие ставки, налоги, режимы и рыночные данные перед применением проверяйте по первичным источникам и у профильных специалистов.

## Быстрый запуск за 10–15 минут

### 1. Создайте отдельного Telegram-бота
1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Сохраните токен. Не вставляйте его в код и не публикуйте.
3. Откройте своего нового бота и нажмите Start.

### 2. Загрузите архив в GitHub
1. Создайте новый репозиторий, например `finlab-learning`.
2. Распакуйте архив на компьютере.
3. Загрузите **содержимое** папки проекта в корень репозитория (вместе с `.github`).
4. В Settings → Secrets and variables → Actions → New repository secret добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_CHAT_ID` — ваш Telegram chat ID.
   - `MINI_APP_URL` — (необязательно, но удобно) HTTPS-адрес опубликованного Mini App, например `https://USERNAME.github.io/REPOSITORY/`; тогда в ежедневном сообщении появится кнопка открытия приложения. Чтобы узнать chat ID: после добавления токена в Secret запустите workflow `Get chat ID` вручную (Actions → Get chat ID → Run workflow), затем напишите боту `/start`; ID будет в логах workflow. Либо используйте надёжный личный ID-бот, которому доверяете.
5. Для безопасности проверьте, что репозиторий не содержит токенов и персональных данных.

### 3. Первый тест
- Откройте Actions → `Send learning lesson` → Run workflow.
- Успешный запуск должен прислать урок в Telegram.
- Ежедневный запуск настроен на `05:00 UTC` = `08:00 Europe/Moscow`. GitHub cron может стартовать с задержкой в несколько минут.

### 4. Включите Mini App
1. Settings → Pages → Build and deployment → Source: **GitHub Actions**. Workflow `Deploy FINLAB Mini App to GitHub Pages` автоматически публикует Mini App и данные курса на корень Pages-сайта.
2. Дождитесь публикации HTTPS-адреса вида `https://USERNAME.github.io/REPOSITORY/miniapp/`.
3. В BotFather → `/mybots` → ваш бот → Bot Settings → Menu Button (или `/setmenubutton`) укажите HTTPS-адрес корня Pages-сайта, например `https://USERNAME.github.io/REPOSITORY/`.
4. Перезапустите Telegram и откройте кнопку Menu. Mini App также можно открыть в обычном браузере.

Примечание: Mini App — статическое приложение, прогресс и заметки хранятся локально на устройстве/в браузере. Между разными устройствами они автоматически не синхронизируются. Бот и ежедневная доставка работают независимо от Mini App.

## Структура
- `course/MASTER_PROGRAM.md` — большая карта программы на 12 месяцев.
- `course/lessons.json` — 30 стартовых уроков с материалом, практикой, тестами и источниками.
- `course/exams.json` — экзамены и интеграционные кейсы.
- `course/sources.md` — библиотека первоисточников и учебных ресурсов.
- `src/send_daily.py` — отправка урока через Telegram Bot API.
- `src/get_chat_id.py` — безопасная подсказка для определения chat ID через `getUpdates`.
- `miniapp/index.html` — Telegram Mini App / веб-версия.
- `.github/workflows/` — ежедневная доставка, ручной тест и получение chat ID.

## Как добавлять уроки
Добавьте объект в `course/lessons.json`, соблюдая поля `id`, `month`, `week`, `day`, `title`, `hook`, `minutes`, `body`, `formula`, `case`, `advisor_application`, `quiz`, `sources`. Старайтесь ссылаться на первичные источники, ставить дату у рыночных цифр и отличать факт от прогноза. Затем commit/push — новый урок сразу доступен боту и Mini App.

## Учебный стандарт
Каждый полноценный урок рассчитан на 20–30 минут: парадокс/история, объяснение механизма, финансовая математика, исторический или актуальный кейс, связь с российским рынком и международной практикой, применение в разговоре с клиентом, сложный тест. Ответы теста не показываются до выбора. Есть пояснения к каждому ответу.

## Дисклеймер
Не используйте материалы как замену действующему законодательству, официальной документации биржи/регулятора или инвестиционному заключению. Для налогов, санкций, допуска инструментов и правил инфраструктуры указывайте дату проверки и используйте актуальные первоисточники.
