# FINLAB — академия инвестиций

## Состав
- `index.html` — приложение для GitHub Pages из корня репозитория.
- `miniapp/index.html` — та же Mini App-страница в папке miniapp.
- `course/lessons.json` — 30 стартовых уроков с материалом, формулами, кейсами и тестами.
- `course/roadmap.json` — дорожная карта на 365 дней.
- `.github/workflows/deploy-pages.yml` — публикация через GitHub Actions.

## Загрузка
Загрузите содержимое архива в корень репозитория `fin_academy`, сохраняя папки и пути. Если GitHub спросит про совпадающие файлы, замените `index.html` и workflow; добавьте папку `course` и остальные файлы. В Settings → Pages выберите публикацию через GitHub Actions. После зелёной галочки откройте `https://dryaginmax74reg-lgtm.github.io/fin_academy/`.

Прогресс и заметки в этой версии хранятся локально в браузере. Архив не содержит Telegram bot token и не подключает серверное хранилище. Материалы носят образовательный характер и не являются индивидуальной инвестиционной рекомендацией.
