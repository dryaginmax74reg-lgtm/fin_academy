# FinLab Academy («Знания»)

Ежедневная программа из 60 уроков по инвестициям и финансам: материал на 10–15 минут, интерактив, тест на 15 минут, карточки повторения.

## Структура
- `miniapp/index.html` — собранное приложение (публикуется на GitHub Pages).
- `miniapp/lessons/N.json` — уроки; `lessons/index.json` собирается автоматически.
- `src/` — исходники (`app.js`, `style.css`, `catalog.json`). Сборка: `python3 tools/build.py`.
- `apps-script/Code.gs` — приём результатов в Google Таблицу (шаги в начале файла).

Адрес: https://dryaginmax74reg-lgtm.github.io/fin_academy/

Прогресс сохраняется на устройстве и, если подключён Apps Script, в Google Таблице. Материалы образовательные и не являются индивидуальной инвестиционной рекомендацией.

## Ежедневная учёба — вся программа сразу

Внутри того же FINLAB: кнопка «Ежедневная учёба» на главной и в программе, прямая ссылка https://dryaginmax74reg-lgtm.github.io/fin_academy/#daily.

- Доступны все 30 занятий. Ничего не нужно ждать по календарю. Основной курс из 60 тем остаётся на месте, его номера и прогресс не меняются.
- №1–6 восстановлены из материалов репозитория. Точные исходные тексты из чата недоступны; для №3–4 порядок тем предполагается по программе. №7–12 перенесены из доступной истории «Ежедневная учёба». Исходные интерактивные вопросы чата не извлеклись — для этих уроков составлены новые проверяемые задания. №13–29 собраны из существующих материалов FINLAB с указанием исходных номеров; №30 — итоговая работа по всем 29 темам.
- Разбор появляется после ответа. Вопросы бывают расчётными, с выбором, соответствиями, порядком действий и кейсами. Результат от 70% считается зачётом. Закрытое ежедневное занятие продолжается с сохранённого шага; попытки и ответы доступны в истории.
- Недельный накопительный экзамен открывается на дату последнего воскресенья, месячный — последнего завершённого месяца (либо в последний день текущего). Включаются только темы, чей тест фактически пройден к этой дате, независимо от оценки. Еженедельный — по два задания с темы, месячный — по три. Итоговая аттестация №30 доступна сразу.
- Прогресс и черновики хранятся локально в браузере. Экспорт/импорт переносит завершённые результаты, ответы и карточки, объединяя их с текущими. Незавершённые сессии из внешнего файла не импортируются. Без экспорта или подключённой таблицы телефон, Telegram и компьютер не синхронизируются автоматически. Apps Script синхронизирует оценки, но не полные тексты ответов.
- Telegram SDK вызывает `ready` и `expand`, подключена кнопка «Назад». Никакой регистрации и токена бота для открытия веб-приложения не требуется. Живое открытие через конкретного Telegram-бота отдельно не проверено: его адрес и настройки в репозитории отсутствуют.

Новые темы и углубления добавляются по запросу пользователя. Автоматическая генерация и ежедневные уведомления не включены.

## Контент и российские истории

Добавлена подборка из четырёх российских и двух американских историй: ГКО-1998, ставка 20%, приостановка торгов и курс рубля в 2022 году; SVB и GameStop. В каждой разделены факт, объяснение механизма, ограничения аналогии и вопрос клиенту; есть первичный источник и проверяемый вопрос. В «Арсенал → Истории» доступны фильтры подборок РФ и США. Эти новые истории доступны сразу, остальные открываются после тестов основного курса.

См. [редакционные правила и результаты обзора](docs/CONTENT.md). Все 134 прежние истории не проходили полную пофактную перепроверку в этом обновлении.

## Разработка и публикация

`python3 tools/build.py` собирает приложение; `node tools/check.mjs` проверяет программу, ключи ответов, расчёт экзаменационных периодов, сохранение, скрытие ответов и сборку. GitHub Actions выполняет оба шага перед публикацией Pages, в том числе при изменениях `src/` и `tools/`.

Ежедневные материалы: `miniapp/daily/N.json` и `index.json`; дополнительные истории: `miniapp/daily/cases.json`; интерфейс: `src/daily.js`. Редактируйте готовые JSON непосредственно. `import_daily.py`, `daily_questions.py`, `complete_daily.py` и `editorial_cases.py` — одноразовые инструменты импорта: не запускайте их при обычной сборке, иначе они заменят ручные правки. Для первоначального импорта истории требуется внешний JSON, он намеренно не включён в репозиторий.
