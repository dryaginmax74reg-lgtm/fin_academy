# FinLab Academy

Ежедневная программа из 60 уроков по инвестициям и финансам: материал на 10–15 минут, интерактив, тест, карточки повторения.

- `miniapp/index.html` — приложение одним файлом. Публикуется на GitHub Pages через `.github/workflows/deploy-pages.yml`.
- Прогресс хранится в браузере устройства. Запись в Google Таблицу работает, когда страница открыта внутри Claude.

Адрес: https://dryaginmax74reg-lgtm.github.io/fin_academy/
